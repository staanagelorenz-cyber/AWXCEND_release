# AWXCEND for Android

**[Download AWXCEND.apk](https://github.com/staanagelorenz-cyber/AWXCEND_release/raw/main/AWXCEND.apk)** · version 1.2.7 (build 10)

AWXCEND is a gamified fitness app: camera-counted workouts, quests, dungeons, food logging and an AI coach. You can also use it in your browser at [awxcend.com](https://awxcend.com).

## Install

1. On your Android phone, tap the download link above.
2. Open the downloaded file. If Android asks, allow your browser to **install unknown apps** (Settings → Apps → your browser → Install unknown apps).
3. Tap **Install**, then open AWXCEND and sign in.

## Update

Download the new APK and install it over the one you have. Your account and everything you logged stay; they live on your AWXCEND account, not on the phone.

The app tells you when a new version is out (a bar at the top, and Settings → Help and about), and shows the version you have.

## Versions

See [CHANGELOG.md](CHANGELOG.md). `latest.json` is what the app reads to check for updates.

## Safety

Only download AWXCEND from this page or awxcend.com. Every version is signed with the same AWXCEND key, so Android refuses to install a fake over the real app.
